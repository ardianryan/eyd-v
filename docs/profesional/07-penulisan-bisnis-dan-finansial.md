# Panduan Penulisan Bisnis, Keuangan, & Finansial

Panduan ini mengatur standardisasi penulisan laporan keuangan, prospektus, materi penawaran investasi, dan korespondensi bisnis korporat berdasarkan kaidah **EYD Edisi Kelima**, konvensi Otoritas Jasa Keuangan (OJK), dan Standar Akuntansi Keuangan (SAK).

---

## 1. Penulisan Simbol Mata Uang & Angka
* **Lambang Rupiah**: Tulis `Rp` tanpa tanda titik dan tanpa spasi sebelum digit bilangan.
  * Benar: `Rp50.000.000`
  * Salah: `Rp. 50.000.000`, `Rp 50.000.000,-`
* **Pemisah Ribuan & Desimal**:
  * Tanda titik (`.`) digunakan sebagai pemisah ribuan.
  * Tanda koma (`,`) digunakan sebagai pemisah bilangan desimal: `7,5%` (bukan `7.5%` dalam register bahasa Indonesia).
* **Rentang Nilai**: Gunakan tanda pisah *en dash* (`–`):
  * `Rp10.000.000–Rp20.000.000` (atau *antara Rp10.000.000 dan Rp20.000.000*).

| Istilah Asing | Padanan Baku Bahasa Indonesia |

| *hedging* | lindung nilai |
| *break-even point* | titik impas |
| *escrow* | rekening penampung / rekening bersama |
| *compound interest* | bunga majemuk |
| *mutual fund* | reksa dana |
| *underwriter* | penjamin emisi |
| *liquidity* | likuiditas |
| *leverage* | daya ungkit |
| *dividend* | dividen |

## 3. Gaya Bahasa Laporan Korporasi
* Gunakan kalimat aktif dan lugas dalam mendeskripsikan kinerja keuangan.
* Hindari ungkapan spekulatif tanpa rujukan data audit atau proyeksi keuangan yang terverifikasi.
