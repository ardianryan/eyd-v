# Kaidah Peluluhan Fonem K, T, S, P (Morfofonemik Bahasa Indonesia)

Salah satu sumber kesalahan paling umum dalam penulisan naskah bahasa Indonesia dan generasi teks AI adalah penerapan prefiks *meN-* dan *peN-* pada kata dasar yang diawali fonem **/k/**, **/t/**, **/s/**, dan **/p/**.

Dokumen ini menyajikan rumus sistematis, aturan peluluhan, pengecualian, dan contoh baku sesuai kaidah tata bahasa baku bahasa Indonesia dan EYD Edisi V.

---

## 1. Kaidah Utama (Syarat K-V / Konsonan Diikuti Vokal)

> **Kaidah:**
> Fonem pertama kata dasar berupa konsonan **k**, **t**, **s**, atau **p** akan **LULUH** (melebur) menjadi alomorf sengau homorganik (**ng**, **n**, **ny**, **m**) apabila fonem KEDUA setelahnya adalah **HURUF VOKAL** (a, i, u, e, o).

### Tabel Peluluhan Fonem KTSP:

| Fonem Awal | Huruf Kedua | Hasil Peluluhan | Contoh Kata Dasar | Bentuk Baku meN- | Bentuk Nonbaku (Salah) | Bentuk Baku peN- |
|:---:|:---:|:---:|:---|:---|:---|:---|
| **k** | Vokal | **ng** | *kirim* | **mengirim** | *mengkirim* | **pengirim** |
| | | | *kunci* | **mengunci** | *mengkunci* | **pengunci** |
| | | | *kelola* | **mengelola** | *mengkelola* | **pengelola** |
| **t** | Vokal | **n** | *tulis* | **menulis** | *mentulis* | **penulis** |
| | | | *tolak* | **menolak** | *mentolak* | **penolak** |
| | | | *tari* | **menari** | *mentari* | **penari** |
| **s** | Vokal | **ny** | *sapu* | **menyapu** | *mensapu* | **penyapu** |
| | | | *salin* | **menyalin** | *mensalin* | **penyalin** |
| | | | *sosialisasi* | **menyosialisasikan** | *mensosialisasikan* | **penyosialisasi** |
| | | | *sukses* | **menyukseskan** | *mensukseskan* | **penyukses** |
| **p** | Vokal | **m** | *pakai* | **memakai** | *mempakai* | **pemakai** |
| | | | *pukul* | **memukul** | *mempukul* | **pemukul** |
| | | | *pesona* | **memesona** | *mempesona* | **pemesona** |
| | | | *pengaruhi* | **memengaruhi** | *mempengaruhi* | **pemengaruh** |

> [!IMPORTANT]
> Kata serapan yang diawali konsonan tunggal K/T/S/P dan huruf keduanya vokal **tetap luluh**:
> * *sosialisasi* -> **menyosialisasikan** (bukan *mensosialisasikan*)
> * *sukses* -> **menyukseskan** (bukan *mensukseskan*)
> * *konversi* -> **mengonversi** (bukan *mengkonversi*)
> * *target* -> **menargetkan** (bukan *mentargetkan*)
> * *populer* -> **memopulerkan** (bukan *mempopulerkan*)

## 2. Pengecualian 1: Gugus Konsonan (Kluster / Konsonan Ganda)

> **Kaidah:**
> Apabila fonem kedua dari kata dasar tersebut adalah **HURUF KONSONAN** (membentuk gugus konsonan / kluster seperti *kr-*, *tr-*, *sp-*, *pr-*, *kl-*, *st-*), maka fonem awal **TIDAK LULUH**.

### Contoh Gugus Konsonan:
* *kritik* (k-r) -> **mengkritik** (bukan *mengritik*)
* *kristal* (k-r) -> **mengkristal**
* *traktir* (t-r) -> **mentraktir** (bukan *menraktir*)
* *transfer* (t-r) -> **mentransfer**
* *sponsor* (s-p) -> **mensponsori** (bukan *menyponsori*)
* *stimulasi* (s-t) -> **menstimulasi**
* *produksi* (p-r) -> **memproduksi** (bukan *memroduksi*)
* *protes* (p-r) -> **memprotes**
* *klasifikasi* (k-l) -> **mengklasifikasikan**

---

## 3. Pengecualian 2: Kata Dasar Berawalan Imbuhan *per-* atau *ber-*

Kata bentukan bertingkat yang diawali morfem *per-* atau *ber-* tidak diluluhkan:
* *perhatikan* (dasar: hati -> perhati) -> **memperhatikan** (bukan *memerhatikan*)
* *perbaiki* -> **memperbaiki**
* *perdaya* -> **memperdaya**
* *percepat* -> **mempercepat**
* *perluas* -> **memperluas**

---

## 4. Pengecualian 3: Kata Berasal dari Satu Suku Kata (Monosilabel)

Kata yang hanya terdiri atas satu suku kata mendapatkan alomorf **menge-** dan **penge-**:
* *cat* -> **mengecat**, **pengecat**
* *bom* -> **mengebom**, **pengebom**
* *las* -> **mengelas**, **pengelas**
* *tes* -> **mengetes**, **pengetes**
* *cek* -> **mengecek**, **pengecek**
* *lap* -> **mengelap**, **pengelap**
* *pel* -> **mengepel**, **pengepel**

---

## 5. Pengecualian Khusus (Diferensiasi Makna / Historis)

1. **Kata *kaji*:**
   * **mengaji**: membaca Al-Qur'an / melafalkan ayat suci.
   * **mengkaji**: meneliti, mempelajari secara kritis/akademis.
2. **Kata *punya*:**
   * Mempertahankan bentuk **mempunyai** (tidak menjadi *memunyai*).
